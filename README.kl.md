## Umiatsiaaqqat inuinnaat aamma takutinneqarput

Paasissutissat tamarmik takutinneqartarput. Umiatsiaaraq AIS-imik
nassiussisoq nunap assingani umiarsuartut takutinneqassaaq: aqqa, MMSI
sumiiffialu. Ikinnerusunik takusaqarusukkuit, ammalortup qeqqanit
ungasissusia annikillisiguk.
